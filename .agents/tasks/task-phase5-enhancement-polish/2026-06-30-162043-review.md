## ROCm detection subprocess (unchanged from v1)

```python
result = subprocess.run(
    ["rocm-smi", "--showid"],
    capture_output=True,
    text=True,
    timeout=10,
)
```

The script confirms ROCm presence via `os.path.exists("/opt/rocm")` before this call, so the PATH resolution will find the correct binary in practice. The 10-second timeout prevents hangs. Using `/opt/rocm/bin/rocm-smi` would tighten the execution surface but is not blocking for a demo-oriented script.
